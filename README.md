# Data Analytics Internship – Incubein Foundation

## About the Project

This repository showcases the work completed during my **45-day Data Analytics Internship at Incubein Foundation**.

The project focused on collecting, processing, analysing and visualising startup-related data to help the organisation gain insights into startups and support its incubation activities.

## Projects Included

### 1. Startup Data Analysis Dashboard

**Tools:** Power BI, Google Sheets, Excel

- Analysed startup information and incubation records.
- Cleaned and processed data for accurate analysis.
- Created an interactive dashboard in Power BI.
- Recreated the dashboard in Google Sheets.
- Analysed startup distribution by sector, location and incubation year.
- Tracked active and exited startups.
- Analysed incubation duration.

### 2. Startup Form Responses Dashboard

**Tools:** Google Sheets

- Processed startup application form responses.
- Created a separate dataset for analysis while preserving the original responses.
- Developed a dashboard to analyse startup applications.
- Included filters for sector, year, startup stage, legal entity, location and month.
- Visualised startup distribution and application trends.

### 3. Startup Data Web Scraping

**Tools:** Python, Playwright, Scrapling and other supporting libraries

- Collected startup information from publicly available sources.
- Extracted details such as company name, official website, email, phone number and LinkedIn profile where available.
- Organised the collected information into structured datasets.
- Processed the data for further analysis.
